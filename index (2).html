🔗 ESP32 से Connect करें

ESP32 Serial Monitor में दिखा IP डालें। phone/PC और ESP32 एक ही WiFi पर हों। अगर यह page ESP32 के IP से ही खोला है तो IP खाली छोड़ सकते हैं।

ESP32 को USB cable से इस device में लगाएँ, Connect दबाकर COM port चुनें। Chrome / Edge ज़रूरी है। (Arduino Serial Monitor बंद रखें — port एक बार में एक ही app इस्तेमाल कर सकता है।)
